**WHAT IS LINUX**
Linux is the kernal, the kernal means the core that controls the hard ware, the files and all the processes and permissions of the computer
-THE SHELL (BASH)
This is the program that interpretes the command from a human readavle language to a machine language that gets the kernal to perform tasks that the user wants. Different types of shell are bash, zshell etc
**THE TERMINAL** 
This is the window environment that displays the shell. This is the black window environment that looks scary and unappealing 
-COMMAND LINE INTERFACE (CLI)
This is where text is written in and written out.
**LS COMMAND**
1. ls -l = long listing, shows permissions, size and also hidden files
2. ls -a = shows long listings and dot files
3. ls -lh = shows files in human readable format
4. ls -lR = list the whole folder tree 
**Creating things** 
1. mkdir - makes a directory 
2. mkdir -p a/b/c - makes nested directories where folder a is created with another folder b in the folder a and the folder c is created inside folder b.
3. touc - This command creates an empty file 
**Copying and moving**
1. cp file.txt backup.txt = This copies the content of file.txt into the file backup.txt
2. cp -r folder1 folder2 = this command copies folder1 into folder2 
3. mv file.txt /tmp/ = this command moves the file.txt into the folder /tmp 
4. mv old.txt new.txt = this command renames the file old.txt to new.txt
